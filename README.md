# DemoAndroid

Application Android (Java) de calculatrice à 3 écrans :
- **MainActivity** : écran d'accueil
- **CalculsActivity** : saisie de deux nombres et choix de l'opération (+, −, ×, ÷)
- **ResultatActivity** : affichage du résultat et de l'opération

Fonctionnalités : design Material 3, gestion des erreurs (champ vide, division par zéro), mode paysage.
